You have access to the following tools:

## get_notes
Retrieve the notes belonging to the user.

Parameters: none.

Returns: List of notes with id, title, created_at, and content preview.

## create_note
Create a new note for the user.

Parameters:
- title (string, required): Title of the note
- content (string, required): Content/body of the note

Returns: Created note with id and metadata.

## update_note
Update an existing note.

Parameters:
- note_id (string, required): ID of the note to update
- title (string, optional): New title
- content (string, optional): New content

Returns: Updated note.

## delete_note
Delete a note. Always ask for user confirmation before calling this.

Parameters:
- note_id (string, required): ID of the note to delete

Returns: Confirmation of deletion.
